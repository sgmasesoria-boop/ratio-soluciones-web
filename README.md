# Ratio Soluciones — web pública

Sitio estático responsive para presentar las soluciones de Ratio a particulares, autónomos y pequeños negocios.

## Vista previa

Abre `index.html` en un navegador. No requiere instalación ni servidor para revisar el diseño.

## Antes de publicar

- Completar en `aviso-legal.html` la razón social o nombre legal, NIF/CIF y domicilio fiscal.
- Revisar los textos legales con un profesional según la actividad y forma jurídica reales.
- Sustituir o ampliar los ejemplos por casos y opiniones reales verificadas cuando existan.
- Construir el área privada antes de activar el acceso de clientes; la web actual muestra únicamente una vista informativa del sistema previsto.
- Conectar el formulario a la futura plataforma si se desea recepción y confirmación por correo sin utilizar el canal de mensajería.
- Valorar fotografías propias y un logotipo definitivo.
