# Ratio Soluciones — web inicial

Sitio estático responsive preparado como primera propuesta para Ratio Soluciones.

## Vista previa

Abre `index.html` en un navegador. No requiere instalación ni servidor para revisar el diseño.

## Antes de publicar

- Completar en `aviso-legal.html` la razón social o nombre legal, NIF/CIF y domicilio fiscal.
- Revisar los textos legales con un profesional según la actividad y forma jurídica reales.
- Confirmar el compromiso de respuesta de 24 horas o cambiar ese texto.
- Sustituir o ampliar los ejemplos de servicios por casos reales.
- Conectar el formulario a un servicio de formularios o backend si se desea recepción sin abrir la aplicación de correo.
- Valorar imágenes propias, testimonios verificables y un logotipo definitivo.
