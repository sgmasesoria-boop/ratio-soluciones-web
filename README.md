# Ratio Soluciones — web pública

Web responsive orientada a particulares en Andalucía y la Comunidad de Madrid. Presenta soluciones para deudas, banca, vivienda, seguros, familia y consumo, con un formulario guiado que remite las consultas a sergio@ratiosoluciones.es sin admitir documentación.

## Construcción

```bash
npm run build
```

El resultado se genera en `dist/`, incluido el worker de publicación.

## Alcance actual

- Web pública y páginas de servicio.
- Aviso legal, privacidad y cookies completos con los datos facilitados por el responsable.
- Presentación coherente con el portal privado simplificado.
- Sin almacenamiento documental en la web ni en el portal.

El portal privado se mantiene en un proyecto separado y requiere conexión, pruebas y revisión antes de activar clientes reales. El texto legal debe revisarse si cambia la actividad, el modelo contractual o los proveedores técnicos.
